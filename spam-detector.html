Is this message spam?

A text classifier that flags spam messages, chosen on the mistake users mind most, and shipped as a web app where anyone can paste a message and get an answer.

~5,600messages, only about 1 in 8 spam
131 / 150spam messages caught in the test set
10real messages wrongly flagged
3models compared before choosing
Problem

With so little spam, a model can score high accuracy while missing most of it. Both mistakes matter, but not equally: letting spam through is annoying, while hiding a real message can cost someone something important.

Findings

Naive Bayes gave the best balance.

KNN almost never flagged a real message, but it missed over a third of the spam. The Decision Tree caught more spam but flagged 32 real messages. Naive Bayes sits closest to the ideal corner.

Shipped as an app, not a notebook.

The model runs behind a Flask endpoint. Besides the verdict, the app shows the spam probability and the trigger words it found, so a non-technical user can see why.

Decision
  1. Choose on the trade-offJudge models on missed spam and hidden messages, not accuracy.
  2. Explain the answerProbability and trigger words make the verdict easy to trust or question.
  3. Balance only the training dataSMOTE on the training set, so test results reflect real message mix.
